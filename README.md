# Building and Configuring a Small Office Network

This project was developed as part of the NTI Summer Training Program – August 2024.  
It focuses on designing and implementing a functional small office network using Cisco technologies, VLANs, and inter-VLAN routing.

## 🛠 Project Overview
This project simulates the full lifecycle of a basic enterprise network — from initial topology design to final testing — with weekly milestones.

## 🧰 Tools & Technologies
- **Cisco Packet Tracer**
- **CCNA-level Routing and Switching**
- **Router-on-a-Stick Configuration**

## 📌 Key Concepts
- VLAN configuration and trunking
- Inter-VLAN routing
- Subnetting and IP planning
- Network documentation and troubleshooting

## 📂 Files
- `Topology.png` – Network design diagram
- `IP_Scheme.xlsx` – IP addressing table
- `configs/` – Folder containing all Cisco device configuration scripts
- `final_report.pdf` – Final documentation and testing summary
